# ナノビーズ図案メーカー

カワダ「ナノビーズ」(nanobeads®) の **全55色** に対応した、アイロンビーズの図案作成アプリです。
写真やイラストを読み込むだけで、ナノビーズの色に合わせた図案・カラーチャート・印刷用PDFを作れます。
スマホ・iPad・パソコンのブラウザで動き、GitHub Pages で公開できます（サーバー不要）。

## 主な機能

| 機能           | 内容                                                                                                                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 画像から図案   | 写真・イラストを読み込み（ファイル選択／ドラッグ＆ドロップ／貼り付け）、ナノビーズの色に自動変換。CIEDE2000 による色合わせ                                                                               |
| ネット画像検索 | キーワードで自由に使えるライセンスの画像（[Openverse](https://openverse.org/)）を約100件表示して選べる。作者・ライセンス表示付き                                                                         |
| 背景の透明化   | 自動（画像のふちの色を判定）／手動（画像をタップして「消す」「残す」を指定）。透過PNGもそのまま対応                                                                                                      |
| 大きさ         | プレートの枚数（28×28ピン）またはビーズの数で指定。完成サイズ・必要なプレート枚数を表示                                                                                                                  |
| 色の調整       | 使う色（全55色・12/24/48色セット・マイカラー）、最大色数、ディザ、明るさ・コントラスト・あざやかさ、ノイズ除去、ふちどり、とうめい・メタリックの使用                                                     |
| カラーチャート | 使う色・記号・品番・個数・必要な袋数（1袋1,000個）と金額の目安。持っているセットを引いた買い物計算、買い物メモのコピー                                                                                   |
| 色の差し替え   | 図案の色をまとめて別の色へ（近い色の候補つき）、または「おまかせ」でその色を使わずに作り直し                                                                                                             |
| 手動ビーズ配置 | ペン・消しゴム・塗りつぶし・スポイト、元に戻す/やり直し、対称に描く（左右・上下・上下左右）、つながりチェック（離れたビーズの検出）                                                                      |
| フリーモード   | 白紙から自由に描く。下絵の画像をうすく重ねてなぞることも可能。図案全体の左右反転・上下反転・1つずつずらす・まん中に寄せる                                                                                |
| 保存・印刷     | 画像（PNG：記号つき／ビーズ風／ドット）、印刷用PDF（全体図＋プレートごとの拡大図・座標つき）、共有                                                                                                       |
| つくるモード   | プレートごとに、選んだ色の場所だけを光らせて表示。置いたビーズにチェックして進捗を管理。画面スリープ防止                                                                                                 |
| マイ図案       | ブラウザに自動保存（IndexedDB）。名前でさがす・並べかえ・名前の変更・コピー・削除（えらんでまとめて削除、削除直後の「元に戻す」）                                                                        |
| バックアップ   | すべて（またはえらんだ）図案を1つのファイルに書き出し、別の端末で読み込んで移せる（同じ図案は新しいほうを残す）                                                                                          |
| その他         | スマホ・iPad 対応（ピンチズーム・2本指移動・下部タブ）、ダークモード、PWA（ホーム画面に追加・オフライン動作）、キーボードショートカット、アプリ内の確認ダイアログ（LINE などのアプリ内ブラウザでも動作） |

## ナノビーズのデータについて

- 色名・品番：カワダ公式カタログ／卸サイトの単色商品一覧（全55色）
- 色の値：公式商品ページのビーズ拡大写真から採取し、露出・ホワイトバランスを補正した**目安**です。実物とは異なる場合があります
- 1袋1,000個・253円（税込）、ビーズ φ2.6mm×H2.8mm、プレート 28×28ピン（約8cm角）
- 48色セットの内容は公開情報からの推定を含みます
- 本アプリは非公式のファンメイドツールです。「ナノビーズ」「nanobeads」は株式会社カワダの商標です

## 開発

```bash
npm ci            # 依存関係のインストール
npm run dev       # 開発サーバー (http://localhost:5173)
npm run build     # 本番ビルド (dist/)
npm run preview   # ビルド結果の確認
```

### テスト

```bash
npm test                 # 単体テスト (Vitest)
npm run test:coverage    # 単体テスト + カバレッジ (coverage/index.html)
npx playwright install chromium   # 初回のみ
npm run test:e2e         # 総合テスト (Playwright: PC / スマホ / iPad の3画面サイズ)
npm run lint             # ESLint
npm run format:check     # Prettier
npm run typecheck        # TypeScript
```

- 単体テスト（`src/**/*.test.ts(x)`）：色変換・CIEDE2000（Sharma らのテストデータ）・画像→図案変換・色数制限・ディザ・背景透過・パターン操作（対称・反転・移動）・保存形式・バックアップ・PDF生成・画像検索（API モック）・ストア操作・マイ図案の管理・各画面部品
- 総合テスト（`e2e/`）：サンプル／画像ファイルからの作成、サイズ変更、背景透過（自動・手動）、色数制限、手動編集と元に戻す、対称に描く・反転・まん中に寄せる、色の差し替え、PNG/PDF/ファイル保存、自動保存と再読み込み、マイ図案（名前の変更・さがす・えらんで削除と元に戻す・バックアップの書き出しと読み込み）、トップ画面・保存タブからの削除、つくるモード、画像検索、レスポンシブレイアウトを PC・スマホ・iPad 相当の画面で確認

## 公開 (GitHub Pages)

`main` ブランチへ push すると GitHub Actions（`.github/workflows/ci.yml`）が次を実行します。

1. Lint / フォーマット / 型チェック / 単体テスト（カバレッジ） / ビルド
2. 総合テスト（Playwright: PC・スマホ・iPad）
3. すべて成功したら GitHub Pages へデプロイ

初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** にしてください。
公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/` です（ベースパスはリポジトリ名から自動設定）。

プルリクエストではテストとビルドのみ実行されます。依存関係は Dependabot が毎月更新を提案します。

## 技術構成

- React 19 + TypeScript + Vite、状態管理は Zustand
- 画像変換は Web Worker で実行（CIELAB / CIEDE2000、Floyd–Steinberg ディザ）
- PDF は依存ライブラリなしで生成（ページを canvas で描画して JPEG を埋め込み）
- vite-plugin-pwa によるオフライン対応
- 画像や図案は端末内だけで処理・保存（画像検索を使ったときは検索ワードが Openverse に送信されます）
